# Scénario 7 : Consulter le fond commun

## Nom du Scénario
Consulter le fond commun

## Description
Un membre accède aux œuvres libres de droits disponibles gratuitement dans le fond commun de la bibliothèque.

## Acteurs
- **Membre** : Utilisateur authentifié
- **Système** : Application de bibliothèque numérique

## Préconditions
- Le membre est connecté à son compte
- Des œuvres sont disponibles dans le répertoire "fond_commun"
- Les œuvres ont été validées et sont libres de droits

## Étapes
1. Le membre accède à la section "Fond commun"
2. Le système affiche la liste des œuvres libres de droits
3. Le membre peut filtrer par catégorie (Livres, Musique, Vidéos, Articles)
4. Le membre peut rechercher par titre, auteur ou mots-clés
5. Le membre sélectionne une œuvre qui l'intéresse
6. Le système affiche les détails de l'œuvre (métadonnées, description, aperçu)
7. Le membre peut consulter l'œuvre directement en ligne
8. Le membre peut télécharger l'œuvre sans restriction
9. Le système enregistre la consultation/téléchargement dans les statistiques
10. Le membre peut laisser un commentaire ou une évaluation (optionnel)

## Résultat attendu
Le membre accède librement aux œuvres du domaine public et peut les consulter ou télécharger sans contrainte.
