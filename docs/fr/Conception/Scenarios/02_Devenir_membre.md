# Scénario 2 : Devenir membre

## Nom du Scénario
Devenir membre

## Description
Un utilisateur s'inscrit à la bibliothèque numérique pour devenir membre et accéder aux services de partage et d'emprunt d'œuvres.

## Acteurs
- **Utilisateur** : Personne souhaitant devenir membre
- **Système** : Application de bibliothèque numérique

## Préconditions
- L'application est installée et fonctionnelle
- L'utilisateur a accès à l'interface web
- L'utilisateur dispose d'une adresse email valide

## Étapes
1. L'utilisateur accède à la page d'inscription
2. L'utilisateur saisit ses informations personnelles (nom, prénom, email)
3. L'utilisateur choisit un nom d'utilisateur unique
4. L'utilisateur définit un mot de passe sécurisé
5. Le système vérifie l'unicité du nom d'utilisateur
6. Le système valide le format de l'email
7. Le système crée le compte utilisateur
8. Le système génère une clé de chiffrement personnelle pour l'utilisateur
9. Le système envoie un email de confirmation
10. L'utilisateur confirme son inscription via le lien email
11. Le système active le compte membre

## Résultat attendu
L'utilisateur devient membre de la bibliothèque avec un compte actif et peut accéder aux fonctionnalités de base.
