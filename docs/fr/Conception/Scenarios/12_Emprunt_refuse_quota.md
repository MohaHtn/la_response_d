# Scénario 17 : Dépôt refusé (espace libre dépassé)

## Nom du Scénario
Dépôt refusé (espace libre dépassé)

## Description
Un membre tente d'emprunter une œuvre mais se voit refuser l'accès car il n'y a plus de place disponible dans le serveur.

## Acteurs
- **Membre** : Utilisateur tentant d'emprunter une œuvre
- **Système** : Application de bibliothèque numérique

## Préconditions
- Le membre est connecté à son compte
- Le serveur de la plateforme n'a plus d'espace libre pour stocker les documents

## Étapes
1. Le membre essaie de déposer une oeuvre
2. Le système lui répond que le serveur n'a plus d'espace libre pour stocker les documents

## Résultat attendu
L'emprunt est refusé avec une explication claire.
