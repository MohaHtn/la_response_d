# Glossaire Technique du projet - Bibliothèque Numérique Décentralisée

## Description technique
Développement d'une application web utilisant Python/Pyramid côté serveur, avec choix entre SolidJS ou Bootstrap côté client, et gestion documentaire via Git.

---

## Glossaire Technique

### A
- **Architecture en couches** : Patron architectural organisant le code en couches distinctes (présentation, métier, données).
- **Architecture orientée services** : Style architectural où les fonctionnalités sont exposées comme des services indépendants.
- **Attributs de qualité** : Caractéristiques non fonctionnelles d'un système (performance, sécurité, maintenabilité, modularité, évolutivité).

### B
- **Bootstrap** : Framework CSS traditionnel pour créer des interfaces web responsives rapidement.

### C
- **CI/CD (Continuous Integration/Continuous Deployment)** : Pratiques d'intégration et de déploiement continus.

### D
- **Design patterns** : Solutions réutilisables à des problèmes courants de conception logicielle (Singleton, Factory, Observer, Strategy).
- **Documentation** : Ensemble des documents techniques décrivant l'architecture, les choix de conception et les processus.
- **Dossier** : Répertoire de stockage des livres numériques correspondant à une bibliothèque organisée.

### F
- **Fichier PDF** : Représentation numérique d'un document dans un format portable contenant toutes ses pages.
- **Framework Web** : Ensemble d'outils facilitant la création d'applications destinées à être exposées sur le Web.

### G
- **Gemini** : IA de Google utilisée pour la reconnaissance de texte dans les images de fichiers PDF.
- **Git** : Système de contrôle de version distribué utilisé pour gérer les documents et le code source.
- **Guide de nommage** : Document définissant les conventions de nommage pour assurer la cohérence du code.

### I
- **Intelligence artificielle** : Utilisation d'algorithmes avancés pour la reconnaissance de texte et l'analyse documentaire.
- **Intégration continue** : Pratique consistant à intégrer fréquemment les modifications de code avec validation automatique.

### J
- **JavaScript** : Langage de programmation utilisé côté client pour les interfaces dynamiques.

### L
- **Linters** : Outils d'analyse statique du code pour détecter les erreurs et faire respecter les conventions.

### M
- **Markdown** : Langage de balisage léger utilisé pour la documentation et les fichiers de sortie.
- **Mermaid** : Outil de création de diagrammes à partir d'une syntaxe textuelle, intégrable dans Markdown.
- **Micro-services** : Architecture où l'application est décomposée en services indépendants et déployables séparément.

### O
- **Obsidian** : Outil de prise de notes et de documentation utilisant le format Markdown avec support des diagrammes.

### P
- **Pixtral** : IA de Mistral permettant de reconnaître le texte ET la disposition d'une page dans un fichier PDF.
- **PlantUML** : Outil permettant de créer des diagrammes UML à partir d'un langage de description textuelle.
- **Pyramid** : Framework web Python permettant de traiter les requêtes HTTP et de créer des applications web.
- **Python** : Langage de programmation de haut niveau, simple à utiliser, choisi pour le développement du projet.

### R
- **React** : Framework JavaScript pour créer des interfaces utilisateur dans les navigateurs web.
- **Refactoring** : Processus d'amélioration du code sans changer son comportement externe.
- **RUP (Rational Unified Process)** : Méthodologie de développement logiciel itérative et orientée objet.

### S
- **SolidJS** : Framework moderne basé sur JSX, performant et flexible pour les interfaces client.

### T
- **TAL/METAL** : Langage de templates hérité de Zope/Plone, utilisé avec Pyramid pour la compatibilité.
- **Test d'intégration** : Type de test vérifiant que les nouvelles fonctionnalités n'introduisent pas de régressions dans les autres parties du système.
- **Test unitaire** : Test de base vérifiant qu'une fonctionnalité spécifique fonctionne conformément aux spécifications.

### U
- **UML (Unified Modeling Language)** : Langage de modélisation visuelle pour représenter l'architecture et la conception des systèmes.

### V
- **Visual Studio Code** : Éditeur de code avec extensions pour Markdown et développement collaboratif.
- **Vues architecturales** : Différentes perspectives sur un système (vue logique, de processus, de développement, physique).

---

## Technologies et outils spécifiques

### Langages
- **Python** : Langage principal côté serveur
- **JavaScript** : Langage côté client
- **HTML/CSS** : Technologies web de base

### Frameworks et bibliothèques
- **Pyramid** : Framework web Python (imposé)
- **SolidJS** ou **Bootstrap** : Choix pour l'interface client
- **TAL/METAL** : Système de templates

### Outils de développement
- **Git** : Gestionnaire de versions
- **PlantUML/Mermaid** : Création de diagrammes
- **Obsidian/Markdown Memo** : Documentation
- **Linters** : Contrôle qualité du code

### Intelligence Artificielle
- **Gemini** : OCR Google
- **Pixtral** : OCR Mistral avec analyse de mise en page

### Architecture
- **Modularité** : Développement en modules indépendants
- **CLI (Command Line Interface)** : Fonctionnalités utilisables en ligne de commande
- **Déploiement** : Gestion des versions et de l'infrastructure
