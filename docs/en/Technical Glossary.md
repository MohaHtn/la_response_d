# Technical Glossary - Decentralized Digital Library Project

## Technical Description
Development of a web application using Python/Pyramid on the server side, with choice between SolidJS or Bootstrap on the client side, and document management via Git.

---

## Technical Glossary

### A
- **Layered Architecture**: Architectural pattern organizing code into distinct layers (presentation, business, data).
- **Service-Oriented Architecture**: Architectural style where functionalities are exposed as independent services.
- **Quality Attributes**: Non-functional characteristics of a system (performance, security, maintainability, modularity, scalability).

### B
- **Bootstrap**: Traditional CSS framework for creating responsive web interfaces quickly.

### C
- **CI/CD (Continuous Integration/Continuous Deployment)**: Continuous integration and deployment practices.

### D
- **Design Patterns**: Reusable solutions to common software design problems (Singleton, Factory, Observer, Strategy).
- **Documentation**: Set of technical documents describing architecture, design choices and processes.
- **Directory**: Storage repository for digital books corresponding to an organized library.

### F
- **PDF File**: Digital representation of a document in a portable format containing all its pages.
- **Web Framework**: Set of tools facilitating the creation of applications intended to be exposed on the Web.

### G
- **Gemini**: Google AI used for text recognition in PDF file images.
- **Git**: Distributed version control system used to manage documents and source code.
- **Naming Guide**: Document defining naming conventions to ensure code consistency.

### I
- **Artificial Intelligence**: Use of advanced algorithms for text recognition and document analysis.
- **Continuous Integration**: Practice of frequently integrating code changes with automatic validation.

### J
- **JavaScript**: Programming language used client-side for dynamic interfaces.

### L
- **Linters**: Static code analysis tools to detect errors and enforce conventions.

### M
- **Markdown**: Lightweight markup language used for documentation and output files.
- **Mermaid**: Diagram creation tool from textual syntax, integrable in Markdown.
- **Microservices**: Architecture where the application is decomposed into independent and separately deployable services.

### O
- **Obsidian**: Note-taking and documentation tool using Markdown format with diagram support.

### P
- **Pixtral**: Mistral AI allowing recognition of both text AND layout of a page in a PDF file.
- **PlantUML**: Tool for creating UML diagrams from a textual description language.
- **Pyramid**: Python web framework for handling HTTP requests and creating web applications.
- **Python**: High-level programming language, simple to use, chosen for project development.

### R
- **React**: JavaScript framework for creating user interfaces in web browsers.
- **Refactoring**: Process of improving code without changing its external behavior.
- **RUP (Rational Unified Process)**: Iterative and object-oriented software development methodology.

### S
- **SolidJS**: Modern framework based on JSX, performant and flexible for client interfaces.

### T
- **TAL/METAL**: Template language inherited from Zope/Plone, used with Pyramid for compatibility.
- **Integration Test**: Type of test verifying that new features do not introduce regressions in other parts of the system.
- **Unit Test**: Basic test verifying that a specific functionality works according to specifications.

### U
- **UML (Unified Modeling Language)**: Visual modeling language for representing system architecture and design.

### V
- **Visual Studio Code**: Code editor with extensions for Markdown and collaborative development.
- **Architectural Views**: Different perspectives on a system (logical, process, development, physical views).

---

## Specific Technologies and Tools

### Languages
- **Python**: Main server-side language
- **JavaScript**: Client-side language
- **HTML/CSS**: Basic web technologies

### Frameworks and Libraries
- **Pyramid**: Python web framework (required)
- **SolidJS** or **Bootstrap**: Choice for client interface
- **TAL/METAL**: Template system

### Development Tools
- **Git**: Version manager
- **PlantUML/Mermaid**: Diagram creation
- **Obsidian/Markdown Memo**: Documentation
- **Linters**: Code quality control

### Artificial Intelligence
- **Gemini**: Google OCR
- **Pixtral**: Mistral OCR with layout analysis
