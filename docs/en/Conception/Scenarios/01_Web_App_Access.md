# Scenario 1: Web Application Access

## Scenario Name
Web Application Access

## Description
A user accesses the decentralized digital library via their web browser to use digital work sharing and borrowing services.

## Actors
- **User**: Person wishing to use the application
- **System**: Digital library web application

## Preconditions
- The user has a computer or mobile device with Internet access
- A modern web browser is installed on the system

## Steps
1. The user opens their web browser
2. The user enters the web application URL
3. The server responds to the user's request
4. The user can log in or register
5. If the user is connected, they access digital work sharing and borrowing functionalities

## Expected Result
The user accesses the web application and can use its functionalities without local installation.
