# Scenario 2: Becoming a Member

## Scenario Name
Becoming a Member

## Description
A user registers with the digital library via the web application to become a member and access work sharing and borrowing services.

## Actors
- **User**: Person wishing to become a member
- **System**: Digital library web application

## Preconditions
- The user has access to the web interface via a browser
- The user has a valid email address

## Steps
1. The user accesses the registration page from their browser
2. The user enters their personal information (last name, first name, email)
3. The user chooses a unique username
4. The user defines a secure password
5. The system verifies the uniqueness of the username
6. The system validates the email format
7. The system creates the user account
8. The system sends a confirmation email
9. The user confirms their registration via the link received by email
10. The system activates the member account

## Expected Result
The user becomes a library member with an active account and can access basic functionalities via the web application.
