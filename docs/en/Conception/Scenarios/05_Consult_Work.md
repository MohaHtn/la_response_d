# Scenario 5: Consult a Work

## Scenario Name
Consult a Work

## Description
A member consults a digital work.

## Actors
- **Member**: Authenticated user wishing to borrow a work
- **System**: Digital library application
- **OCR AI**: (Pixtral)

## Preconditions
- The member is logged into their account
- The work is available

## Steps
1. The member searches for or browses an available work
2. The member selects the book
3. The book's consultation counter is incremented by 1
4. The member can download and consult the borrowed work

## Expected Result
The member can consult the document.
