# Scenario 12: Deposit Refused (Free Space Exceeded)

## Scenario Name
Deposit Refused (Free Space Exceeded)

## Description
A member attempts to borrow a work but is refused access because there is no more available space on the server.

## Actors
- **Member**: User attempting to borrow a work
- **System**: Digital library application

## Preconditions
- The member is logged into their account
- The platform server has no more free space to store documents

## Steps
1. The member tries to deposit a work
2. The system responds that the server has no more free space to store documents

## Expected Result
The loan is refused with a clear explanation.
