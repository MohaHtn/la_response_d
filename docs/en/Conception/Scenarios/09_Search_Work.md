# Scenario 9: Search for a Work

## Scenario Name
Search for a Work

## Description
A member uses advanced search functionalities to find a specific work in the library.

## Actors
- **Member**: Authenticated user searching for a work
- **System**: Digital library application

## Preconditions
- The member is logged into their account
- Works are available in the library
- The search index is up to date

## Steps
1. The member accesses the search function
2. The member enters their search criteria (title, author, keywords)
3. The member can apply filters (category, year)
4. The system queries the search index
5. The system applies the member's access rights filters
6. The system sorts results by relevance
7. The system displays the list of matching works
8. The member can refine their search with new criteria
9. The member can view details of a found work
10. The system records the search in the member's history

## Expected Result
The member obtains a list of works matching their criteria and can access authorized works.
