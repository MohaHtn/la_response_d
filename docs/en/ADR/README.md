# Architecture Decision Records (ADR)

This directory will contain the Architecture Decision Records for the Decentralized Digital Library project.

## What are ADRs?

Architecture Decision Records (ADRs) are documents that capture important architectural decisions made along with their context and consequences.

## ADR Format

Each ADR should follow this format:
- **Title**: Short noun phrase
- **Status**: Proposed, Accepted, Deprecated, Superseded
- **Context**: Forces at play, including technological, political, social, and project local
- **Decision**: Response to these forces
- **Consequences**: Resulting context, including new problems introduced
