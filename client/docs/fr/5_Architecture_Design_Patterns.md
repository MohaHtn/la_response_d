# Choix d’architecture et Design Patterns — Client

Architecture UI:
- Pages et composants fonctionnels, séparés des services d’accès API.
- Configuration via variables `VITE_*`.

Patterns recommandés:
- Container/Presentational — séparation logique entre état et affichage.
- Adapter — transformation des réponses API en modèles UI.
- Strategy — stratégies de tri/filtrage.
- Observer — réactivité état/UI.
