# Glossaire métier et technique — Client

Ce glossaire reprend les principaux termes utilisés côté interface utilisateur.

## Métiers
- Œuvre: document numérique (PDF, audio, vidéo, article) consultable via l’UI.
- Membre: utilisateur authentifié qui interagit avec l’UI.
- Bibliothécaire: rôle de modération ayant accès à des écrans dédiés.

## Techniques (frontend)
- Composant: unité UI réutilisable (page, formulaire, liste, etc.).
- Store/État: structure de données réactive reflétant l’état de l’application.
- Service API: module JS chargé d’appeler l’API backend.
