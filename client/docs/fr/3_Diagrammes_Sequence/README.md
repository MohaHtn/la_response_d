# Diagrammes de séquence — Client

Les diagrammes de séquence détaillent l’interaction entre l’utilisateur, l’UI, et l’API.

Sources globales (PlantUML) à consulter:
- `../../../docs/fr/Conception/Diagrammes d'états transitions/`
- Scénarios: `../../../docs/fr/Conception/Scenarios/_Scenarios.md`

Parcours recommandés à modéliser côté UI:
- Authentification (connexion / déconnexion)
- Recherche d’œuvre et affichage des résultats
- Proposition d’une œuvre (upload + progression)
- Modération (listes, actions, statut)
