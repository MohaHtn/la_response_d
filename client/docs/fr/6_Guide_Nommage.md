# Guide de nommage — Client

- Composants: `PascalCase` (ex.: `ModeratorPage.jsx`).
- Hooks/fonctions: `camelCase`.
- Constantes: `SCREAMING_SNAKE_CASE`.
- Fichiers: alignés sur le composant principal (`QuarantinePage.jsx`).
- Traductions/i18n: clés stables, éviter le texte en dur.
- Respect du vocabulaire (cf. Glossaire) dans l’UI et les noms.
