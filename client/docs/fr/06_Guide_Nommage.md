# Guide de nommage — Frontend

- Composants React: `PascalCase` (ex.: `ModeratorPage.jsx`).
- Fichiers de page: nom = nom du composant de page (ex.: `Home.jsx`).
- Hooks/fonctions utilitaires: `camelCase` (ex.: `useAuth`, `fetchWorks`).
- Constantes: `SCREAMING_SNAKE_CASE`.
- CSS/Modules: alignés sur le composant (`ModeratorPage.module.css`).
- Dossiers: courts et explicites (`pages`, `components`, `services`).
- Clés i18n/labels: stables, explicites, sans espaces.
- Respect du glossaire (termes métier cohérents dans l’UI et les commentaires).
