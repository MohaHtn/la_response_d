# Paramétrage des variables d’environnement — Serveur

Variables supportées:
- `PIXTRAL_API_KEY` — clé API Pixtral
- `GEMINI_API_KEY` — clé API Gemini
- `REDIS_URL` — ex.: `redis://localhost:6379/0`

Fichier d’exemple:
```
server/.env.example
```
Contenu recommandé:
```
PIXTRAL_API_KEY=
GEMINI_API_KEY=
REDIS_URL=redis://localhost:6379/0
```
