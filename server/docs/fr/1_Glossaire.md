# Glossaire métier et technique — Serveur

Termes clefs côté backend.

## Métiers
- Œuvre (Document): entité principale du domaine (contenu + métadonnées + statut).
- Membre: utilisateur identifié (droits, quotas, historique).
- Bibliothécaire: rôle en charge de la modération.

## Techniques (backend)
- Service: logique applicative (ex.: OCR, modération, export Markdown).
- Repository: accès aux données (ex.: Redis, stockage de fichiers).
- Provider IA: service externe (Gemini, Pixtral) pour l’OCR/vision.
