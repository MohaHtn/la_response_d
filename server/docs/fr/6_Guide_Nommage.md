# Guide de nommage — Serveur

- Python: `snake_case` pour fonctions/variables, `PascalCase` pour classes.
- Modules et packages: noms courts et significatifs.
- Constantes: `SCREAMING_SNAKE_CASE`.
- Exceptions: suffixe `Error`.
- Logs: inclure contexte (identifiants, statut, action) et messages actionnables.
- Cohérence avec le glossaire pour la terminologie métier.
